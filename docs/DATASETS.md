# Datasets

Every dataset file is listed in `data/manifest.json` with its source URL, licence, access date and SHA-256.
Raw downloads live in `data/raw/` and processed tables in `data/processed/` (both git-ignored; rebuild with
the commands below). Provenance classes used everywhere in the project:

| Class | Meaning |
|---|---|
| `public_real` | real-world observations from a published dataset |
| `room101_measured` | measurements from the project's real room (ESP32-S3 board in Office A) |
| `synthetic` | generated by the project's simulator (never real measurements) |
| `prediction` | output of a trained model |
| `derived` | computed from other values |

```
python scripts/fetch_datasets.py          # download (needs internet), verify checksums
python scripts/preprocess_datasets.py     # build data/processed/, record their checksums
scripts/make_synthetic_corpus.sh          # synthetic corpus from the twin (data/synthetic/)
```

## 1. UCI Occupancy Detection (real) - used for occupancy and a real-data thermal check

| | |
|---|---|
| Source | UCI Machine Learning Repository, dataset 357, DOI 10.24432/C5X01N; data by Luis M. Candanedo |
| Paper | Candanedo & Feldheim (2016), *Energy and Buildings* 112, 28-39 |
| Licence | CC BY 4.0 (UCI landing page, read 23 Oct 2026) |
| Downloaded from | the dataset author's repository `github.com/LuisM78/Occupancy-detection-data` (the UCI host is refused by this environment's network proxy); byte-identical to the copies already in `Dataset/UCI/` |
| Variables | Temperature (degC), Humidity (%RH), Light (lux), CO2 (ppm), HumidityRatio (kg/kg, derived), Occupancy (0/1, from time-stamped photographs) |
| Sampling | 1 minute; one office in Mons, Belgium, February 2015 |
| Files | datatest.txt 2-4 Feb (2,665 rows), datatraining.txt 4-10 Feb (8,143), datatest2.txt 11-18 Feb (9,752); no overlap; 2 gaps > 5 min (between files); no missing values |
| Class balance | 23.1 % occupied overall |
| Limitations | one room, heating season, a few occupants; light is a strong cue because people switched it - in an automated building the controller switches the lights |

**Duplicate warning.** `Dataset/Kaggle_Room_Occupancy/datatraining.txt`, `datatest.txt`, `datatest2.txt` are
byte-identical to the UCI files; `Occupancy.csv` (also in `data/raw/kaggle_occupancy/`) is the three files
concatenated and `file.csv` is `datatest.txt` without dates. The "Kaggle" data is therefore not an
independent dataset. The previously deployed model (`models/final_unified_occupancy_pipeline.pkl`) was
trained on UCI plus these copies, so its scores on any UCI file are not held-out results.

## 2. Building Data Genome Project 2 (real) - used for energy prediction

| | |
|---|---|
| Source | `github.com/buds-lab/building-data-genome-project-2` (BUDS Lab, National University of Singapore) |
| Paper | Miller et al. (2020), *Scientific Data* 7, 368, doi:10.1038/s41597-020-00712-x |
| Licence | repository LICENSE file: "Attribution-ShareAlike 4.0" (Creative Commons BY-SA 4.0) |
| Files used | `metadata.csv`, `weather.csv`, `meters/cleaned/electricity_cleaned.csv` (Git LFS objects) |
| Units | electricity kWh per hour (paper: "kWh sum" for energy meters); weather from NOAA ISD-Lite (degC, oktas, m/s, mm, hPa); timestamps local time (checked: Panther air temperature peaks at 14:00) |
| Subset | site "Panther" (metadata coordinates 28.52 N, 81.38 W, US/Eastern: humid subtropical, the BDG2 site closest to Colombo's climate), office buildings with >= 90 % of hours present from 1 Jun 2016 to 31 Dec 2017: **23 of 28** offices (4 have no cleaned electricity meter, 1 fails the completeness rule). Panther's cleaned electricity starts in late May 2016 (61 % of 2016 is empty for every office), hence the study period. |
| Processing | weather gaps up to 3 h interpolated and flagged (none occurred in the period); missing electricity never filled |
| Limitations | university offices in one US site; observed weather used as a perfect forecast in the day-ahead model |

## 3. Weather for the twin (synthetic, documented)

`twin/climate.py` generates Colombo weather from published monthly climate normals (1991-2020 temperature;
NOAA 1961-1990 humidity and sunshine), deterministic per seed. It is not measured weather. Measured hourly
Colombo weather (Open-Meteo archive, NASA POWER, Meteostat, NOAA ISD) could not be downloaded: those hosts
are refused by this environment's network proxy and by the linked PC's shell. To add it later, download an
hourly series for 6.93 N 79.85 E and drive `ScenarioClimate` from it.

## 4. Synthetic corpus (simulator)

`scripts/make_synthetic_corpus.sh` produces `data/synthetic/<scenario>_seed<k>_<controller>.csv.gz` and a
`.meta.json` per file (configuration, code commit, SHA-256, validation result). Rows: one per simulated room
every 5 min (1 min for the occupancy check) with the true state, what the sensors delivered (None =
missing), validated commands, powers and outdoor conditions; provenance `synthetic`. Training seeds 11-16 and
31; test seeds 21-23 and 32 (never used for training). Every file passed `twin/validation.py`.

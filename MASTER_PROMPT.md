# 7. BUILDING SIMULATOR

Rooms 102–126 must have simulated environmental inputs.

Do NOT generate arbitrary random noise.

Build a physically plausible simulation.

The simulator should consider:

* time of day
* occupancy schedules
* outdoor temperature
* solar radiation
* daylight
* room type
* floor
* thermal inertia
* previous room temperature
* HVAC state
* lighting state
* occupancy heat gains
* equipment loads

Use deterministic seeded randomness where randomness is required.

The simulator must produce realistic temporal correlations.

For example:

```text
08:00 → occupancy increases
09:00 → internal heat gains increase
12:00 → solar gain increases
13:00 → occupancy variation
17:00 → occupancy decreases
18:00 → HVAC demand decreases
22:00 → building mostly unoccupied
```

The simulator should behave like a simplified digital building environment rather than a random-number generator.
